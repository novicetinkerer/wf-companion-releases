WF Companion

An unofficial desktop companion for Warframe on Windows: inventory prices, warframe.market, a relic reward overlay, mastery planning and alerts.

Download for Windows Releases & source
Built with AI assistance. Much of this project's code was written by a large language model (LLM), directed, reviewed and tested by the author. It may contain mistakes: use at your own risk and report problems on GitHub.
Ban risk. Inventory scans open the game process read-only (nothing is written or injected). No third-party tool that opens the game process can be guaranteed safe from anti-cheat or Digital Extremes' rules. Safe mode turns scans off completely; everything else keeps working.
If Windows Security blocks it. Your data is kept in Documents, which Controlled folder access protects. If the install fails ("error writing to file") or the app says it can't save: Windows Security → Ransomware protection → Allow an app through Controlled folder access → add WF Companion (%LOCALAPPDATA%\WF Companion\wf-companion.exe). If it was flagged as a threat: Windows Security → Protection history → Allow on device, then install again. Still "error writing to file"? Quit WF Companion from the tray and retry.
Inventory & market
Parts, mods, arcanes and relics with live warframe.market prices. Post and edit orders, auto-close them after trades.
Relic overlay
Prices, ducats and owned/needed set parts under each reward card; wanted parts marked.
Relics, Wanted, Ducanator
Radiant values, refine advice, trace fodder, wanted-part highlights, ducat planning.
Mastery
MR progress bar and the easiest items to build and rank next, with the relics you own.
Alerts
Fissures, open-world cycles, Circuit, Baro. Desktop, Discord and Telegram notifications.
Light while gaming
Closes its window when Warframe starts; the tray app uses about 15 MB.
